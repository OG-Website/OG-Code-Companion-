Open OG Companion.exe or Start OG Companion.cmd. Keep the complete folder together when sharing it. The Windows package includes Python and the Qt desktop runtime; recipients do not need to install Python to open the app.

BUILD CODE
Choose a language, type what you want to build and select Get starter code / Update. The Code tab contains editable source; How to build it explains the approach and next steps. Supported CSV-to-JSON and local file-integrity starters work without AI. Other matching requests can show a reference snippet or retrieve real documentation examples. A connected local model supplies custom programs and updates.

For example, enter: cybersecurity, file libraries, security considerations. The supplied Python starter creates a SHA-256 file manifest and compares later file changes. It handles local files; it is not a malware detector. Its comments explain how to run it and the guidance explains what the operations do.

Edit code directly, copy it or save it. Changing the description and choosing Update includes your current code. Expand code requests another useful addition, and Undo update restores the preceding source. New request clears the search and description while retaining code. Clear code asks before discarding unsaved work. Ctrl+Enter starts a build; Ctrl+S saves source.

BROWSE LIBRARIES
Choose Packages, Documentation or GitHub and enter an exact library name or task keywords. The documentation selector includes 244 collection titles across 837 editions. All API topics browses an edition; Previous and Next reach further results. Select a library and choose Get code examples, or double-click it. The chosen example opens in Build code. Complete collection loads all available distinct blocks from an edition. Load source URL retrieves another public HTTPS documentation page, raw source file or repository. Save all examples exports code with its references and licence details.

Seven package-registry adapters cover PyPI, npm, NuGet, Maven Central, crates.io, Packagist and RubyGems. The language/tool selector has 22 choices, including CMake. Other languages can use documentation and public source discovery. There is no fixed global snippet total: providers and individual pages determine available examples.

LOCAL MODELS
Refresh models discovers running Ollama services, LM Studio and compatible localhost APIs, including recognised Windows service processes using non-default ports. Select your own model from the full table, then Connect selected model. Nothing connects automatically. Add service URL supports another localhost base URL; it is saved in that user's profile. Service token supports an authenticated service for the current session only. No token or model weights are included in the shared folder.

Ollama lists installed models. LM Studio's native model APIs include downloaded and loaded models; code generation needs a language model, so embedding models are identified and rejected for that action. Connecting a downloaded model through the supported LM Studio native API loads that selected model. A generic compatible API exposes the models its server makes available. Start the recipient's own service to use its models; OG Companion does not directly open arbitrary model-weight files without a serving runtime.

LIBRARIES WITHOUT AI
The package supplies 31 teaching snippets across 14 languages, two complete Python foundations and 14 licensed documentation collections containing 84,512 summed source blocks. These blocks include configuration, commands and transcripts, rather than 84,512 complete programs. The collections and source licence files are included. Cached and supplied examples remain available with Online sources switched off. Uncached remote material needs internet access. AI is optional for browsing, source retrieval, editing, copying and saving.

PRIVACY AND LICENCES
Online searches send keywords to public providers. Code generation sends your request and code to the chosen localhost service; that service's model configuration determines where inference runs. OG Companion never automatically executes retrieved/generated code or installs packages. Source URLs and licence details accompany examples. Runtime licence notices are under og_companion_assets/runtime-licences, with the Python licence under OG Runtime. Keep these files with any shared copy.
